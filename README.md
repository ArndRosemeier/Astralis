# Astralis (working title)

A 4X strategy game in the spirit of Master of Orion 2, set in our **real stellar neighbourhood** and
shown in **3D**: real stars and known exoplanets, the gaps filled each game with planets we can't
detect yet, sublight travel (one turn = 5 years), biology-driven alien species, and battles fought by
strategies you design and then watch.

**Status: planning.** There is no code yet. The design lives in [docs/design.md](docs/design.md) (the
overview, decisions and open questions) and the detail documents in [docs/design/](docs/design/):

1. [Research](docs/design/1-research.md)
2. [Economy](docs/design/2-economy.md)
3. [Governments](docs/design/3-governments.md)
4. [Ships](docs/design/4-ships.md)
5. [Diplomacy and the Concord](docs/design/5-diplomacy.md)
6. [Ground combat](docs/design/6-ground-combat.md)
7. [Versions, What's new and the title screen](docs/design/7-title-and-versions.md)

A sibling of [StarLord](https://github.com/ArndRosemeier/StarLord), from which it takes the
infrastructure (deterministic sim, GameHub multiplayer, three.js layer, changelog), not the rules.
